# Linear B Open Control Corpus

**Version 0.1.0 — architecture and provenance foundation**

Linear B Open Control Corpus is a provenance-first, machine-readable research project for Linear B designed primarily as a **known-answer control corpus** for cross-script computational research.

Its immediate role is not to replace established Linear B editions, databases, or Mycenaean Greek scholarship. It provides a reproducible observational layer that can be separated from a deciphered linguistic gold layer so methods developed for Linear A and Cypro-Minoan can be tested without seeing the answers first.

## Alignment
This repository is the third script adapter in the same research family as:
- `hawkinsnick/Linear-A`
- `hawkinsnick/Cypro-Minoan`

It conforms to Aegean Epigraphy Interchange v0.1 and Experiment Gate v1 while keeping Linear-B-specific phonetic, lexical, morphological, syntactic and linguistic information in extensions.

## 0.1.0 scope
- governance and research-ethics foundation;
- observation/gold-layer separation;
- source/provenance and rights policy;
- DĀMOS v2 derivative acquisition target pinned by identity and SHA-256;
- cross-project interoperability contract;
- known-answer experiment gate;
- no redistributed DĀMOS corpus bytes;
- no calibration result;
- no claim that this is a comprehensive Linear B corpus.

## Core rule
**The neutral Aegean core may constrain Linear B. Linear B's deciphered categories may not redefine the neutral core.**
