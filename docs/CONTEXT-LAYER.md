# Physical and contextual evidence — 4.3

Context is evidence, not decoration. Site, find area/spot, support, object class, scribal hand, museum/inventory, joins, chronology and layout are stored as source-attributed assertions rather than flattened truths.

The DĀMOS-derived v2 release reports hand, find context, object class, joins, museum and inventory metadata. 4.3 defines how those fields enter the project but does not claim record-level population without verified local bytes.

Hand labels are scholarly classifications and remain sourced assertions. Contextual similarity is not linguistic identity and cannot expose gold-layer information.
