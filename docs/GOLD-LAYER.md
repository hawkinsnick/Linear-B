# Deciphered gold layer — 4.4

Linear B's decipherment makes a known-answer layer possible; it does not make that layer provenance-free.

Gold includes readings/normalizations, lexical identifications, lemmas, morphology, syntax and semantic interpretation. Each assertion requires a scholarly source and may carry uncertainty and competing analyses.

Blind experiments deny gold access until detector predictions, exclusions and scoring rules are frozen. 4.4 defines this contract but populates zero gold assertions because the authenticated corpus bytes have not been locally materialized and record-level source mapping has not been audited.
