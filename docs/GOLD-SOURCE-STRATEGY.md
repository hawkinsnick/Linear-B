# Gold-source strategy — 4.9.3

The authenticated DĀMOS-derived v2 asset supplies transliteration and context, not the linguistic answer layer needed for known-answer scoring.

DĀMOS's public project documentation states that its underlying database is annotated for morphology and syntax and provides translation and lexical information for words. It also supports multiple simultaneous analyses for ambiguous linguistic units. This makes DĀMOS the preferred primary machine-readable gold witness **if the annotation can be obtained through a legitimate, reproducible route**.

## Acquisition rule

Accepted:
1. a documented public export/API; or
2. a research export supplied or explicitly authorized by the DĀMOS maintainers.

Not accepted:
- circumventing undocumented/private interfaces;
- reconstructing the answer key from model knowledge;
- flattening disputed analyses into one project-authored truth.

## Multi-witness rule

LiBER and scholarly editions may provide additional epigraphic/bibliographic witnesses. Apparent agreement is not independent replication when databases inherit the same underlying edition. Lineage therefore travels with every assertion.

## 5.0

The gold-acquisition gate remains closed until record/word alignment, ambiguity preservation and source lineage are reproducible. This is a scientific gate, not merely a software dependency.
