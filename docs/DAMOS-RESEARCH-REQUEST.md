# DĀMOS linguistic annotation research request

The Linear B Open Control Corpus is building a provenance-first known-answer calibration for computational methods used on undeciphered Aegean scripts. We have authenticated the CC BY-NC-SA DĀMOS-derived v2 transliteration/context snapshot (5,932 documents) but intentionally have not reconstructed linguistic answers ourselves.

We would be grateful for a legitimate machine-readable research export, or documentation for a supported reproducible access route, to DĀMOS linguistic annotations described in the project's public database documentation: morphology, syntax/case syntax, translation, lexical information and competing analyses/probability where available.

Desired linkage fields are stable document ID plus word/token locator. We will preserve DĀMOS attribution, CC BY-NC-SA terms, uncertainty, competing analyses and source lineage. We do not need images and are not requesting access around any private interface.

The purpose is blind known-answer calibration: predictions are frozen before linguistic gold is revealed, and null/negative results are published.
