# Observation / gold separation — 4.2

4.2 freezes a deny-by-default observation derivation policy.

Permitted detector inputs are graphemic/physical/contextual observations with provenance. Lemmas, morphology, syntax, translations, semantic glosses and other linguistic analyses are forbidden from the blind observation export.

The builder refuses input unless its SHA-256 equals the pinned DĀMOS-derived v2 digest. Unknown corpus envelopes abort rather than guess. Gold-like upstream keys are reported for quarantine. A separate leakage audit recursively rejects forbidden field names in derived output.

Because exact local source bytes were not materialized for this release, the committed observation record count is **0** and the leakage result is **null**. 4.2 claims an executable contract, not a populated corpus.
